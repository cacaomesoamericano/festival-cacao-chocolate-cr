# Festival de Cacao y Chocolate de Especialidad de Costa Rica · 2026

Sitio del festival: 6 y 7 de noviembre, Campus Benjamín Núñez, UNA, Lagunilla de Heredia.

Sitio estático (HTML y CSS, sin dependencias). Para editarlo, modifique `index.html`.

## Publicar con GitHub Pages

1. En el repositorio: **Settings → Pages**.
2. En *Source*, elija **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y guarde.
3. En uno o dos minutos el sitio queda en `https://cacaomesoamericano.github.io/festival-cacao-chocolate-cr/`.

## Pendientes

Reemplazar los textos entre corchetes en `index.html`: enlace de inscripción, correo de contacto, redes y patrocinios.
